# Sound effects

Transition SFX are not committed. Templates expect these file names:

`bass_drop.mp3` · `glitch.mp3` · `impact_boom.mp3` · `text_swoosh.mp3` · `ui_pop.mp3` · `whoosh_1.mp3` · `whoosh_2.mp3`

Grab free equivalents from https://mixkit.co/free-sound-effects/ and save them here with those names.
