# yt-dlp

Link import (TikTok / YouTube / Instagram) uses the standalone **yt-dlp** binary, which is not committed.

Download `yt-dlp.exe` from https://github.com/yt-dlp/yt-dlp/releases/latest and place it here:

```
assets/bin/yt-dlp.exe
```

The server self-updates it on startup. Without it, the app still works — link import is just disabled.
